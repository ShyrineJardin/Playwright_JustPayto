💡 How to Use

  1. Select a Test: Click on any test in the list to select it
  2. Choose Device: Select from desktop browsers (Chrome, Firefox, Safari, Edge), mobile devices (iPhone, Pixel), or tablets (iPad, Pixel Tablet)
  3. Display Mode: Choose "Headed" to see the browser run, or "Headless" to run quietly
  4. Run Test: Click the "Run Test" button to start
  5. Monitor Progress: Watch the output in real-time below
  6. View Results: Wait for completion and check for ✅ or ❌

📱 Available Devices

  • Chromium (Chrome) - Desktop resolution (1280x720)
  • Firefox - Desktop resolution
  • WebKit (Safari) - Desktop resolution
  • Microsoft Edge - Desktop resolution

📱 Mobile Devices:

  • iPhone 12 - 390x844 (portrait)
  • iPhone SE - 375x667

📱 Tablet Devices:

  • iPad Pro - 1024x1366
  • iPad Air - 820x1180
  • Google Pixel Tablet - 1280x800

📌 Tips

  • Mobile Testing: Test on actual mobile device sizes to catch responsive design issues
  • Tablet Testing: Verify your app works on tablet viewports between mobile and desktop
  • Headed mode: Great for debugging - you'll see the browser/device in action
  • Headless mode: Faster - good for quick test runs
  • Chromium Desktop: Recommended for initial testing - fastest and most compatible
  • Multi-device runs: Run the same test on different devices to ensure cross-platform compatibility
  • Can't click Run? Make sure you've selected a test first

🎯 Status Indicators

Idle - Ready to run
Running - Test is in progress
Success - All tests passed ✅
Error - Test failed ❌
