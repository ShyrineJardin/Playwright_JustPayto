💡 How to Use

  1. Select a Test: Click on any test in the list to select it
  2. Choose Browser: Select Chromium, Firefox, or WebKit
  3. Display Mode: Choose "Headed" to see the browser run, or "Headless" to run quietly
  4. Run Test: Click the "Run Test" button to start
  5. Monitor Progress: Watch the output in real-time below
  6. View Results: Wait for completion and check for ✅ or ❌

📌 Tips

  • Headed mode: Great for debugging - you'll see the browser in action
  • Headless mode: Faster - good for quick test runs
  • Chromium: Recommended - fastest and most compatible
  • Can't click Run? Make sure you've selected a test first

🎯 Status Indicators

Idle - Ready to run
Running - Test is in progress
Success - All tests passed ✅
Error - Test failed ❌
