💡 How to Use

  1. Select a Biller: Click on one of the available billers in the left panel
  2. Choose Payment Method: Select from the available payment methods (Credit Card, E-Wallet, Bank Transfer, or Online Bank)
  3. Configure Settings: Choose your browser and display mode
  4. Run Test: Click the "Run Test" button to start testing
  5. Monitor Progress: Watch the output in real-time below
  6. View Results: Wait for completion and check for ✅ or ❌

📌 About Billers

  • Cignal: Cable/Internet billing - requires customer name fields
  • Maynilad: Water utility - simple account number based
  • Meralco: Electricity - simple account number based
  • Bankard: Credit card bills - requires account name and bill date
  • Avon: Distribution orders - requires name and branch

🎯 Status Indicators

Idle - Ready to run
Running - Test is in progress
Success - Test passed ✅
Error - Test failed ❌

  • 🪶 Online Bank: Test payment via institutional banking
