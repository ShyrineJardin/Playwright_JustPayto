💡 How to Use

  1. Select a Test: Click on any test in the list to select it
  2. Choose Device: Select from desktop browsers, mobile, or tablet devices
  3. Display Mode: Choose "Headed" to see the browser run, or "Headless" to run quietly
  4. ZAP Security Scan (optional): Toggle on to route browser traffic through OWASP ZAP for security scanning. Make sure ZAP is running first!
  5. Run Test: Click the "Run Test" button to start
  6. View Results: Wait for completion and check for ✅ or ❌

🛡️ ZAP Security Scanning

What ZAP does:

  • Acts as a proxy between Playwright and your app
  • Passively intercepts all HTTP/HTTPS traffic during the test
  • Flags security issues like XSS, SQL injection, insecure headers, and more
  • Best used on E2E tests — not applicable for Unit and Integration tests

Before enabling: Make sure OWASP ZAP is open and running on your machine. Default address is localhost:8080. Use "Check Connection" to verify.
